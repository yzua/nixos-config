Handoff ${@:-the current RE run}. Read [the contract](../contract.md) and
[the evidence record](../skills/re-intake/references/evidence.md) from this
prompt's resource directory. Inventory work actually completed; do not execute a
new scan, target request, device probe or credential check to embellish a report.

Return engagement/run and authorization expiry, artifact/target/account/device/
page/project identity, host/yolo exposure, provider/release policy, actual skills/
guides read, detected/reviewed versions and capability qualification limitations.
Separate observations, inferences and candidate/confirmed/rejected/blocked claims.
Link approved evidence by hash + flow ID/code/address location; include expected
versus observed tests, partial/missing/truncated data and reproducible commands.

Record owned resources stopped/restored/retained, unresolved cleanup and residual
root/helper/IME/trust/device/browser state. Preserve private originals; release
only approved sanitized outputs without credentials/raw screenshots/logs. Give the
next bounded step and its required skill/gate. For REA work, retain the artifact/
provider/query identities, derived JSON paths, limits and cleanup diagnostics;
record CLI reimport cost rather than implying a persistent engine session.
A resumed run must revalidate scope and ownership; handoff grants no new
permission. Root-only delegation follows the contract.
